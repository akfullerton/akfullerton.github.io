# Andrew Khoi Fullerton portfolio

This project is a static Jekyll site intended for GitHub Pages user-site hosting at `akfullerton.github.io`.

- Keep all public site pages and Jekyll configuration at the repository root.
- Edit page copy in the root Markdown files; shared layout lives in `_layouts` and `_includes`.
- Run `bundle exec jekyll serve --livereload` for a local preview.
- Publish through GitHub Pages from the `main` branch and repository root.
- Do not add application frameworks, backend services, or private résumé/source files to the public repository.
